# ledger-tasks-yylo

Comprehensive guide for using YYLO Ledger task management - a command-line Kanban and task ledger for coding-agent projects that stores board state as hash-chained Markdown inside the repository. Covers all commands (create, list, search, get, mark, update, archive, deps, ready, order, merge), dependency management, merge orchestration, receipts and archives, best practices, and workflow patterns. Use for questions about YYLO Ledger commands, Kanban board operations, task dependencies, or merge and release flows across agent worktrees.
